# 新概念英语学习 App

跨端前端应用，支持 iOS、Android 和 Web 平台。

## 🛠️ 技术栈

- Vue 3 + TypeScript + Vite
- Ionic Vue + Capacitor
- TailwindCSS 4.0
- Pinia + Vue Router

## 🚀 快速开始

### 安装依赖

```bash
pnpm install
```

### 开发

```bash
# Web 开发
pnpm dev

# 构建
pnpm build
```

### Capacitor 原生开发

```bash
# 同步到原生项目
pnpm cap:sync

# 打开 iOS 项目
pnpm cap:open:ios

# 打开 Android 项目
pnpm cap:open:android
```
